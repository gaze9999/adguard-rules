# AdGuard 個人規則清單

這是我個人使用的 AdGuard 過濾規則, 也公開分享給有需要的人 規則依個人使用情境整理 不保證適合所有裝置或網站

## 清單

- [LINE 廣告阻擋](https://raw.githubusercontent.com/gaze9999/adguard-rules/main/line-block.txt): 針對 LINE 相關廣告與追蹤請求
- [網站與 App 廣告阻擋](https://raw.githubusercontent.com/gaze9999/adguard-rules/main/site-app-block.txt): 針對特定網站與 App 的廣告
- [郵件追蹤阻擋](https://raw.githubusercontent.com/gaze9999/adguard-rules/main/mail-block.txt): 針對郵件追蹤像素與開信追蹤

在 AdGuard 的自訂過濾清單中加入所需清單的連結即可 如果遇到功能異常 可先暫停對應清單確認是否由規則造成
